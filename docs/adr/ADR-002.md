# ADR-002: Restricción UNIQUE y bloqueo pesimista contra doble reserva

- **Tipo:** Tecnológica
- **Estatus:** Aceptado

## Contexto
Dos personas podrían reservar el mismo horario al mismo tiempo.

## Decisión
Restricción UNIQUE (médico, fecha_hora, reserva_activa) más bloqueo pesimista y @Version.

## Justificación
La base de datos garantiza la regla incluso con concurrencia, sin depender solo del código.

## Consecuencias
El conflicto se traduce en una respuesta 409.
