# ADR-001: Monolito modular con Spring Boot

- **Tipo:** Arquitectónica
- **Estatus:** Aceptado

## Contexto
Se elige el estilo de la primera versión para una clínica.

## Decisión
Un monolito modular organizado en paquetes (cita, medico, paciente, notificacion, auditoria).

## Justificación
Volumen bajo, un solo equipo y necesidad de transacciones simples entre citas, recordatorios y auditoría.

## Consecuencias
Más simple de operar; se podría separar recordatorios si crece la carga.
